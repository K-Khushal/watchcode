# WatchCode

> Bridge Claude Code permission requests to a Galaxy Watch.

WatchCode lets you approve or deny Claude Code tool-use requests from your wrist — so you can step away from your laptop without blocking an AI coding session.

## Quick start

```sh
npm install -g watchcode
watchcode start
watchcode pair
```

Then sideload the WatchCode APK onto your Galaxy Watch (see [docs/watch-install.md](docs/watch-install.md)).
